# 重查台灣公開報價

名冊採九家建置業者，工作流九筆、文件檢索知識庫六筆。另採傑崴科技的建置加月租與超額對話、Pensieve AI 的個人訂閱，供比較固定費、月費和用量費。各方案的原始網址與比對規則見 [sources.py](sources.py)。

在 Linux 或 WSL 的本專案根目錄執行，使用 Python 3.10 以上版本。

```bash
python3 agents/pricing/collect.py --output /tmp/zhiyan-market-prices.json
python3 -m unittest discover -s agents/pricing -p 'test_*.py'
```

1. 每輪直接讀取賣家網站的公開 HTML（網頁原始碼）。依站方 `robots.txt` 逐站抓取，同一頁供多筆方案共用。每筆附來源網址、頁面 SHA-256（內容指紋）及含金額與單位的原文片段，可依抓取時間核查。
2. 報告的 `prices` 依單位分欄。`terms` 收錄目標方案內匹配的功能、支援、額度與額外費用原文，也會取該業者明確標示的共通條款。`null` 表示此次未擷取到，須回原頁確認。片段可能只呈現部分權益，建置付款也不能直接推定著作權買斷。
3. 每家每個建置類別只取一筆入門方案，套組以整案最低門檻計。建置和月租綁售、按量加購或自助訂閱各自列示。原始平均與中位數保留。全組取得且至少四筆時，使用含端點線性內插的四分位數，以 1.5 倍四分位距篩除離群值，再列保留均價、中位數與排除名單。這是公開報價樣本，實際範圍、權益或成交額另行確認。
4. 報告看到 `review` 時，核對來源的當前方案、幣別、價格和計價單位。待議、區間、必要月租、方案改版、拒絕存取及無法辨認的內容都應人工覆核。程式會將匹配失敗留白，保留其餘有效資料。不完整建置組只提供觀察值統計。全數核對成功回傳 0，有待覆核項回傳 2。
5. 記錄需改動的網址或區段，配合賣家頁面更新名冊後重跑，交接每筆證據與未決項目。官網售價需單獨決定。
